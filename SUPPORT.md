# Support

For installation, usage, and configuration guidance, start with
[README.md](README.md), [SPECIFICATION.md](SPECIFICATION.md), and the project
[wiki](https://github.com/Xyz00777/aom/wiki).

For reproducible bugs or feature requests, use the
[issue tracker](https://github.com/Xyz00777/aom/issues). Include the
AOM version, command line, relevant configuration, and a minimal reproduction
when possible. Do not include credentials or other sensitive data.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md) instead.
